# Carnet du garage mobile — version rapide (essai)

Copie du carnet qui tourne hors de claude.ai pour tester la vitesse.
Les données restent dans le navigateur de chaque appareil (localStorage).
Recherche d'adresse : OpenStreetMap (Photon) sans clé, ou TomTom en direct avec la clé de l'utilisateur (gardée dans son navigateur).
